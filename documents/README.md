# documents/

Положите сюда свои файлы `.docx`. Команды работают с этой папкой без
аргументов, из любого каталога проекта — папка ищется вверх по дереву, а
результат ложится в `chunks/` рядом с ней:

```bash
docx-chunking check        # не теряется ли текст при разборе
docx-chunking sections     # дерево разделов
docx-chunking chunk        # -> chunks/chunks.jsonl
```

Сами документы в репозиторий не попадают: `.gitignore` закрывает `*.docx`
целиком, потому что любой документ здесь — чей-то настоящий, а не пример.
Отслеживается только этот файл.

Полезно начать с `check`: он сравнивает число текстовых узлов в файле с
числом узлов, до которых доходит разбор, и сразу показывает, видит ли
инструмент ваши документы целиком.
